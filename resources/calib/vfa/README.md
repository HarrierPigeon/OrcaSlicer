# VFA test models

- `vfa.drc`: OrcaSlicer's VFA tower.
- `vfa_major_axes.drc`, `vfa_0_90.drc`, `vfa_45_135.drc`, `vfa_30_60.drc`: the "Reth" models from
  "VFA Test - improved angles" by 3D Printing Elves (@3DPrintElves_224347),
  https://www.printables.com/model/1798209-vfa-test-improved-angles, licensed under the GNU General
  Public License v3.0 and included with the designer's permission. They were made from scratch
  with OrcaSlicer's VFA tower and EnigmaTaco's "VFA test gcode for MK4S" (public domain) as
  references, with fins along 0/45/90/135, 0/90, 45/135 and 30/60/120/150 degrees. Converted from
  the published STL files to Draco without other changes.
